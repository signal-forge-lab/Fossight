# Fossight Naming

**English** | [Japanese](NAMING.ja.md)

## Official name and pronunciation

- Product name: **Fossight**
- Official Japanese reading: **フォサイト (Fosaito)**

## Origin of the name

**Fossight** is a coined name combining **FOSS + Sight**.

- **FOSS** — Free and Open Source Software; the software Fossight catalogs and monitors.
- **Sight** — keeping something visible, surveying it, and watching its state over time. This reflects Fossight's role in understanding what each OSS project is for and monitoring Local / Upstream status.

The name also intentionally echoes **Foresight**. Fossight is meant to surface upstream changes and local drift early, before they become unnoticed maintenance debt.

The user-visible product name is **Fossight** in the UI, documentation, and Modora. The official Japanese reading is **フォサイト**.

## Previous name and compatibility identifiers

The previous product name was **OSS Update Watch**. Branding changed to **Fossight**, while several stable internal identifiers remain unchanged to avoid breaking existing scripts and integrations:

- `oss-update-watch` — package / Modora module ID and related compatibility identifiers
- `oss_update_watch` — Python module
- `oss-update-watch-desktop.exe` — desktop executable

These are internal compatibility identifiers, not the user-facing product name.
