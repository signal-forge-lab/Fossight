# OSS Summary Catalog

**English** | [Japanese](oss-summary-catalog.ja.md)

This catalog provides concise, human-readable descriptions for the OSS projects curated in Fossight. It explains what each project is for and the role it can play; live version and Local/Upstream status are intentionally handled by Fossight itself.

## 01. addyosmani/agent-skills

- **Repo:** `addyosmani/agent-skills`
- **Local usage:** `agent-skills` / direct
- **Summary:** A reusable collection of engineering skills for AI coding agents. It structures practices for planning, implementation, testing, debugging, review, and delivery so agents can follow repeatable software-engineering workflows instead of relying on one-off prompts.

## 02. affaan-m/ECC

- **Repo:** `affaan-m/ECC`
- **Local usage:** `ECC` / direct
- **Summary:** A broad coding-agent harness that combines agents, skills, commands, hooks, memory, continuous learning, and automated checks. It is designed to add an end-to-end engineering workflow around coding assistants rather than only generating code snippets.

## 03. agno-agi/agentos-docker

- **Repo:** `agno-agi/agentos-docker`
- **Local usage:** `agentos` / fork
- **Summary:** Deployment and runtime infrastructure for serving AI agents through AgentOS. It packages agents behind APIs and other entry points, with operational tooling for running and managing agent services.

## 04. agno-agi/agno

- **Repo:** `agno-agi/agno`
- **Local usage:** `agno` / fork
- **Summary:** A Python framework and runtime for building agents and agent teams with tools, knowledge, memory, workflows, APIs, and management interfaces. It targets complete agent applications rather than isolated model calls.

## 05. anthropics/skills

- **Repo:** `anthropics/skills`
- **Local usage:** `anthropics-skills` / direct
- **Summary:** Anthropic's reference collection for Agent Skills. It demonstrates how instructions, scripts, and supporting resources can be packaged into reusable capabilities that agents load when needed.

## 06. battersea-dynamics/trading-agent

- **Repo:** `battersea-dynamics/trading-agent`
- **Local usage:** `trading-agent` / direct
- **Summary:** An educational multi-agent short-term trading system using components such as CrewAI, Gemini, Alpaca, and Finnhub. It is useful as a reference architecture for market/news reasoning and paper-trading workflows rather than as guaranteed investment logic.

## 07. ChromeDevTools/chrome-devtools-mcp

- **Repo:** `ChromeDevTools/chrome-devtools-mcp`
- **Local usage:** `chrome-devtools-mcp` / direct
- **Summary:** An MCP server that gives AI agents access to Chrome DevTools capabilities. Agents can inspect and automate pages while using DOM, Console, Network, and Performance data for debugging and browser-based analysis.

## 08. deepseek-ai/deepseek-harness

- **Repo:** `deepseek-ai/deepseek-harness`
- **Local usage:** `deepseek-harness` / direct
- **Summary:** DeepSeek's open-source agent harness for running tool-using AI agents and multi-step tasks. It is a developer-preview foundation for experimenting with agent runtimes, workflows, and orchestration rather than a simple model wrapper.

## 09. DeusData/codebase-memory-mcp

- **Repo:** `DeusData/codebase-memory-mcp`
- **Local usage:** `codebase-memory-mcp` / direct
- **Summary:** A local code-intelligence engine that uses Tree-sitter and LSP information to build a persistent knowledge graph of symbols, calls, routes, and relationships. It lets agents query large codebases semantically through MCP with less repeated file reading.

## 10. DietrichGebert/ponytail

- **Repo:** `DietrichGebert/ponytail`
- **Local usage:** `ponytail` / direct
- **Summary:** A skill-oriented toolkit that pushes coding agents toward simpler implementations and away from unnecessary dependencies or abstractions. It emphasizes complexity, LOC, token, cost, and maintenance reduction before adding new machinery.

## 11. different-ai/openwork

- **Repo:** `different-ai/openwork`
- **Local usage:** `openwork` / fork
- **Summary:** An open-source desktop workspace for sharing skills, MCP integrations, services, and workflows across coding agents. It aims to provide a reusable Cowork/Codex-style work environment rather than coupling capabilities to one assistant.

## 12. dsh-external/dsh_workflow

- **Repo:** `dsh-external/dsh_workflow`
- **Local usage:** `dsh-external-workflow` / direct
- **Summary:** A durable workflow layer for agent execution, with persistent runs, phased work, resume/recovery, and verification. It is used to turn long-running coding tasks into inspectable workflows rather than one-shot conversations.

## 13. Egonex-AI/Understand-Anything

- **Repo:** `Egonex-AI/Understand-Anything`
- **Local usage:** `Understand-Anything` / fork
- **Summary:** A tool for converting code, documentation, and other knowledge sources into explorable knowledge graphs. It helps humans and agents understand where concepts live and how components relate across a codebase or knowledge base.

## 14. FiloSottile/age

- **Repo:** `FiloSottile/age`
- **Local usage:** `age` / direct
- **Summary:** A deliberately simple, modern file-encryption tool and library. It supports public-key and passphrase workflows and is widely used as an encryption backend for tools such as SOPS.

## 15. Finesssee/Win-CodexBar

- **Repo:** `Finesssee/Win-CodexBar`
- **Local usage:** `Win-CodexBar` / direct
- **Summary:** A Windows system-tray application for surfacing AI coding-service usage and quota information. It brings multiple provider dashboards into a compact native-style status experience inspired by CodexBar on macOS.

## 16. getsops/sops

- **Repo:** `getsops/sops`
- **Local usage:** `sops` / direct
- **Summary:** A secrets-management tool that encrypts values inside YAML, JSON, ENV, INI, and binary files while preserving useful file structure. It integrates with age, PGP, and cloud KMS providers and is designed for encrypted configuration stored in Git.

## 17. Git-Agni/prod-FARM-IOS-Core

- **Repo:** `Git-Agni/prod-FARM-IOS-Core`
- **Local usage:** `prod-FARM-IOS-Core` / direct
- **Summary:** An iOS device-farm foundation for registering and monitoring physical iPhones/iPads and running automated tasks. It combines WDA/Appium-style control, live viewing, analysis, scheduling, execution history, and dashboard/API concepts.

## 18. google-labs-code/design.md

- **Repo:** `google-labs-code/design.md`
- **Local usage:** `design.md` / direct
- **Summary:** A specification for communicating design systems to AI coding agents through a structured `DESIGN.md`. It combines machine-readable design tokens with human-readable intent, validation, and accessibility guidance so generated UI follows project design rules.

## 19. google-labs-code/stitch-skills

- **Repo:** `google-labs-code/stitch-skills`
- **Local usage:** `stitch-skills` / direct
- **Summary:** A collection of agent skills and plugins that connect Google Stitch-style design workflows with coding agents. It packages design, build, and utility steps for tools such as Codex, Claude Code, Cursor, and Gemini CLI.

## 20. h4ckf0r0day/obscura

- **Repo:** `h4ckf0r0day/obscura`
- **Local usage:** `obscura` / direct
- **Summary:** A lightweight Rust headless-browser engine with JavaScript execution and Chrome DevTools Protocol support. It explores a smaller browser runtime for automation and agent use cases while aiming for compatibility with common browser-control patterns.

## 21. Hitheshkaranth/OpenTerminalUI

- **Repo:** `Hitheshkaranth/OpenTerminalUI`
- **Local usage:** `OpenTerminalUI` / direct
- **Summary:** An open-source financial terminal UI for traders, researchers, and quantitative teams. A Python/FastAPI backend and React frontend provide a base for market-data, research, and analytics dashboards.

## 22. leonxlnx/taste-skill

- **Repo:** `leonxlnx/taste-skill`
- **Local usage:** `taste-skill` / direct
- **Summary:** A design skill intended to improve the visual judgment of AI-generated frontend work. It supplies practical rules for layout, spacing, typography, color, and component choices to reduce generic or visually weak output.

## 23. letta-ai/letta

- **Repo:** `letta-ai/letta`
- **Local usage:** `letta-upstream-review` / direct
- **Summary:** The historical/landing repository for Letta, formerly MemGPT, a project focused on stateful agents with persistent memory. Current implementation work largely lives in `letta-ai/letta-code`, while this repository remains useful for project context and archived server history.

## 24. letta-ai/letta-code

- **Repo:** `letta-ai/letta-code`
- **Local usage:** `letta-code-upstream-review` / direct
- **Summary:** The current Letta agent harness for building stateful agents with persistent memory, identity, and long-term context. It supports interactive terminal use and longer-running agents that can evolve memory, skills, prompts, and tooling over time.

## 25. mattpocock/skills

- **Repo:** `mattpocock/skills`
- **Local usage:** `mattpocock-skills` / direct
- **Summary:** A reusable set of software-engineering skills for coding agents. It focuses on repeatable practices for design, implementation, testing, debugging, and verification rather than isolated question-answer prompting.

## 26. mem0ai/mem0

- **Repo:** `mem0ai/mem0`
- **Local usage:** `mem0-local` / direct
- **Summary:** A memory layer for AI assistants and agents that extracts, stores, retrieves, updates, and deletes useful long-term information from interactions. It supports personalization workflows and can be used through cloud or self-hosted architectures.

## 27. mem0ai/mem0-mcp

- **Repo:** `mem0ai/mem0-mcp`
- **Local usage:** `mem0-mcp-official-archive` / direct
- **Summary:** The archived standalone MCP server that exposed Mem0 memory functions to MCP clients such as Claude, Cursor, and VS Code. Active official MCP usage moved to a hosted approach, so this repository is mainly useful as an implementation/reference archive.

## 28. microsoft/UFO

- **Repo:** `microsoft/UFO`
- **Local usage:** `UFO` / direct
- **Summary:** Microsoft's research platform for GUI and desktop automation agents. UFO2 focuses on Windows desktop interaction, while UFO3 extends the research toward coordinated multi-device agent workflows and task orchestration.

## 29. nextlevelbuilder/ui-ux-pro-max-skill

- **Repo:** `nextlevelbuilder/ui-ux-pro-max-skill`
- **Local usage:** `ui-ux-pro-max-skill` / direct
- **Summary:** A UI/UX design skill and knowledge base for AI agents, covering visual styles, palettes, typography, industry patterns, accessibility, and responsive design. It helps agents generate and review interfaces against more explicit design guidance.

## 30. oraios/serena

- **Repo:** `oraios/serena`
- **Local usage:** `serena` / direct
- **Summary:** An MCP toolkit that gives coding agents IDE-like semantic code navigation and editing. Through language-server-backed symbol search, references, rename/refactor, and related operations, it supports precise work across large codebases without relying only on text search.

## 31. pbakaus/impeccable

- **Repo:** `pbakaus/impeccable`
- **Local usage:** `impeccable` / direct
- **Summary:** A frontend-design improvement toolkit for coding agents, combining a design skill, focused design commands, browser-based visual review, and heuristics for common AI-generated UI problems. It covers polish, accessibility, responsiveness, animation, and performance-oriented review.

## 32. petrkindlmann/qa-skills

- **Repo:** `petrkindlmann/qa-skills`
- **Local usage:** `qa-skills` / direct
- **Summary:** A large collection of QA and test-engineering skills for AI agents, spanning unit, API, browser, mobile, visual, performance, accessibility, security, CI/CD, and bug-triage workflows. It emphasizes test strategy and risk-based quality work as well as test code generation.

## 33. shiyu-coder/Kronos

- **Repo:** `shiyu-coder/Kronos`
- **Local usage:** `Kronos` / direct
- **Summary:** An open-source foundation model trained for financial candlestick/K-line sequences. It is designed for forecasting and representation tasks on noisy financial time series rather than as a generic sequence model.

## 34. signal-forge-lab/fable_madakana

- **Repo:** `signal-forge-lab/fable_madakana`
- **Local usage:** `fable_madakana` / direct
- **Summary:** A lightweight watcher for ChatGPT Fable-related threads that retrieves updates, deduplicates previously seen messages, stores new notifications, and can reprocess history when needed. It is intended for reliable tracking of conversation updates over time.

## 35. SikandarJODD/animations

- **Repo:** `SikandarJODD/animations`
- **Local usage:** `animations` / direct
- **Summary:** A collection of copy-and-paste animation components for Svelte 5 using tools such as motion-sv, Tailwind CSS, and the shadcn-svelte registry. It provides reusable interaction, hover, transition, and visual-effect building blocks.

## 36. SikandarJODD/cnblocks

- **Repo:** `SikandarJODD/cnblocks`
- **Local usage:** `cnblocks` / direct
- **Summary:** A collection of production-oriented Svelte 5 UI blocks built with shadcn-svelte and Tailwind CSS. It provides larger sections such as hero, pricing, feature, and CTA blocks for SaaS, product, documentation, and landing pages.

## 37. SikandarJODD/sv-agentation

- **Repo:** `SikandarJODD/sv-agentation`
- **Local usage:** `sv-agentation` / direct
- **Summary:** A Svelte UI annotation tool for turning human frontend review comments into structured context for coding agents. It lets reviewers target exact elements or regions and pass actionable, machine-readable feedback back to an agent.

## 38. SikandarJODD/sv-table

- **Repo:** `SikandarJODD/sv-table`
- **Local usage:** `sv-table` / direct
- **Summary:** Data-table components and ready-made table blocks for Svelte 5/SvelteKit. It packages common features such as search, faceted filters, date/number ranges, pagination, sorting, column visibility, resizing, row actions, and CSV export.

## 39. tauricresearch/tradingagents

- **Repo:** `tauricresearch/tradingagents`
- **Local usage:** `tradingagents` / direct
- **Summary:** A multi-agent trading research framework in which specialized LLM agents cover market, fundamentals, news, sentiment, bull/bear research, trading, and risk roles. It connects those roles into a graph for experimentation and backtesting across configurable model and market-data providers.

## 40. trycua/cua

- **Repo:** `trycua/cua`
- **Local usage:** `cua` / direct
- **Summary:** An open-source infrastructure stack for developing, running, training, and evaluating computer-use agents. It covers OS-control drivers, environment/fleet management, benchmarks, data generation, and reproducible computer-use workflows beyond a single desktop-control API.

## 41. vibheksoni/stealth-browser-mcp

- **Repo:** `vibheksoni/stealth-browser-mcp`
- **Local usage:** `stealth-browser-mcp` / direct
- **Summary:** An MCP server for controlling Chrome-family browsers using nodriver, the Chrome DevTools Protocol, and FastMCP. It focuses on robust browser automation, including workflows that encounter login walls or anti-bot checks, while supporting existing signed-in browser profiles.

## 42. Waishnav/devspace

- **Repo:** `Waishnav/devspace`
- **Local usage:** `devspace` / fork
- **Summary:** A local coding-workspace platform for AI agents that can open workspaces, read and edit repository files, and execute commands. It enables persistent codebase work that is difficult to perform reliably in a plain chat-only environment.

## 43. wonderwhy-er/DesktopCommanderMCP

- **Repo:** `wonderwhy-er/DesktopCommanderMCP`
- **Local usage:** `DesktopCommanderMCP` / fork
- **Summary:** An MCP server that gives AI assistants practical local file-system and terminal operations such as search, read, update, directory management, and command execution. It is a general-purpose local execution bridge rather than a semantic code-intelligence engine.

## 44. xyTom/coding-tools-mcp

- **Repo:** `xyTom/coding-tools-mcp`
- **Local usage:** `coding-tools-mcp` / direct
- **Summary:** An MCP toolkit that exposes common local coding primitives to AI chats and agents, including file access, editing, search, and command execution. It aims to provide a reusable coding interface across MCP-compatible clients rather than tying workflows to one IDE.

## 45. yebof/quant-agent

- **Repo:** `yebof/quant-agent`
- **Local usage:** `quant-agent` / direct
- **Summary:** A US-equity multi-agent quantitative trading system with specialized technical, macro, news, SEC-filing, portfolio, risk, position-management, and reflection agents. It combines LLM reasoning with deterministic Python risk controls and Alpaca-oriented execution workflows.

---

## Reading notes

- **direct** — the upstream repository is used or referenced directly.
- **fork** — a local fork or independently modified checkout is maintained relative to an upstream.
- This catalog explains **what each OSS project is for**. Current version, Behind/Ahead/Diverged state, and update history belong to Fossight's live monitoring results and are intentionally not frozen into this document.
